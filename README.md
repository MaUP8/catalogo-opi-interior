# Catálogo OPI · Interior del país

Carta de productos OPI disponibles para clientas del interior, con pedido por WhatsApp.

- Pedido mínimo $ 7.500 a precio profesional; por debajo, el pedido va a precio consumidor final.
- Stock y precios: los actualiza dos veces por día la tarea programada, con los datos de Power BI.
- La página se genera desde el repo `MaUP8/catalogo-opi` con `tools/generar_interior.py`: no editar `index.html` a mano.
